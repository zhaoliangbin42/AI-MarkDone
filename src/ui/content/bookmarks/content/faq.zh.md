# 常见问题

## 可以在哪些网站使用？

完整工作区适用于 ChatGPT，包括页面内阅读器和独立阅读器。Gemini、Claude 和 DeepSeek 仍提供公式复制；以前从这些平台保存的书签也可查看和管理。

## 各项功能在哪里？

- 资料库与设置：点击插件图标打开管理面板
- 功能全览：在设置分类下方查看功能、用法和快捷键
- 复制、书签、阅读器、导出：展开回复下方的工具栏
- 注释与高亮：选中文字后，点击“注释”或色块
- 公式复制：点击公式
- 消息导航：使用页面右下角的上一条、下一条按钮
- 备份：设置 → 数据与备份

## 管理面板可以全屏吗？

可以。点击管理面板右上角关闭按钮旁的“全屏”，展开整个管理面板；再点“退出全屏”恢复窗口。切换大小不会改变当前分类、搜索内容或选择。

## 阅读器有什么用途？

在窗口或全屏模式阅读长回复，用标题大纲查找段落，并在消息间切换。阅读时可以复制 Markdown、添加注释或继续提问。代码块可单独复制和切换换行；片段可暂存到摘录区，方便对照。

摘录区只在当前页面保留，刷新后清空。需要在另一个标签页阅读时，可从页面工具栏打开独立阅读器。它需要手动刷新内容；刷新、发送和定位都需要原 ChatGPT 标签页保持打开。

## 注释怎么用？

选中段落，点击“注释”。随后可将原文和注释一起复制，或插入输入框继续追问。插入后可先检查草稿，再自行发送。

## 能自定义注释模板吗？

打开阅读器右上角设置中的注释复制模板。模板决定原文和注释的排列方式。

提示词是可复用的指令，在设置 → 输入与提示词中管理。复制注释时可以选择一条提示词，放在注释之前或之后。

## 注释和高亮会保存吗？

高亮始终保存到当前浏览器。阅读器设置中的“保存新建的注释”默认关闭；关闭时新注释只留在当前页面，开启后新注释在刷新后仍可查看。已经保存的注释不受影响。

在资料库按对话查看注释与高亮，或打开原页。

## 没写完的注释会怎样？

输入时不会自动保存。点击框外可以继续阅读，注释窗口和里面的文字都会保留；点击“保存”才会提交注释。主动关闭、按 Esc、放弃修改或刷新页面，会丢弃尚未保存的修改。

保存失败时，窗口会保留输入，方便重试。点击“保存”后的注释仍遵循“保存新建的注释”设置，默认不会在刷新后保留新注释；已经持久保存的注释不受该开关影响。

## 能只复制回复的一部分 Markdown 吗？

在 ChatGPT 页面或阅读器中选中文字，点击“复制 Markdown”。文字、公式、代码和列表会保留对应的 Markdown 格式。选中的公式按完整公式复制；部分代码选区只复制实际片段。

ChatGPT 页面默认使用 Cmd/Ctrl + Shift + C；已有自定义组合优先保留。可在设置 → 按钮与快捷键 → 快捷键中修改或停用。阅读器中也使用该页显示的实际组合。

## 能自定义快捷键吗？

可以。在设置 → 按钮与快捷键 → 快捷键中，点击组合录入新按键，也可停用单项或恢复默认。检查覆盖插件内冲突和已知保留按键，不能完整检测系统、浏览器或其他扩展的占用。输入文字时不会触发阅读翻页等操作。

## 反斜杠提示词联想怎么用？

在 ChatGPT 输入框或阅读器发送框的开头，或空白之后输入 `\`，即可查看匹配的提示词，再按触发词过滤。自动联想只列出已启用且设置了触发词的提示词；公式中的反斜杠由公式助手处理。

自动联想开关位于设置 → 按钮与快捷键 → 快捷键。关闭自动联想后，仍可使用已启用的“打开提示词候选”快捷键；没有触发词的提示词也可从手动候选中选择。具体组合以设置页面为准。

## 公式如何复制？

点击原回复中的公式。行内公式默认带 `$...$`，行间公式默认带 `$$...$$`。单个公式和整段 Markdown 的复制格式可分别在设置 → 复制与导出中调整。

开启设置 → 按钮 → 公式中的图片操作后，还可复制 PNG、SVG、MathML，或保存 PNG、SVG；SVG 和 MathML 需要可用的公式源码。输入框的公式预览也提供这些操作。

## 书签可以保存什么？

可以保存对话链接或某条回复。页面书签只保存名称和链接；消息书签保存提问和回复，可供预览和复制。文件夹最多支持四级。

“书签只保存内容摘要”开启后，超过 500 个字符的提问和回复分别保留开头 250 与结尾 250 个字符；完整内容仍可在原对话查看。

## 书签很多时怎么整理？

在左侧选择文件夹，或搜索内容。列表每页显示 20 条。使用书签行内按钮重命名、移动或删除书签；文件夹操作在对应文件夹菜单中。类型筛选、排序、导入导出和批量选择都在“资料库”标题旁。

“选择本页”只选当前页；“全选书签”和“反选书签”会作用于当前筛选结果的所有分页。翻页保留选择；切换文件夹、类型或搜索范围会清空选择。单个文件夹必须为空才能删除。批量删除文件夹会包含其书签及子文件夹，确认前会列出数量。

## 如何导出？

从回复下方或目录预览打开“导出”，选择消息和格式。Markdown 可继续编辑；PDF 会打开浏览器打印窗口，选择“保存为 PDF”即可。PNG 保存为长图片，需要生成多个图片文件时会打包为 ZIP。图片生成期间可查看进度或取消。

需要保留支持的图表或卡片时，可选择离线 Markdown ZIP，将图片附件一起保存。PDF 和 PNG 可选择静态图片或文字占位；无法生成图片的部分会保留可读说明，离线文件不保留交互操作。

## 能隐藏按钮或更换主题吗？

在设置 → 按钮与快捷键 → 按钮中调整页面、消息、公式、选区和目录按钮，并固定常用的页面或消息按钮。主题、字号和主色位于外观与布局。主题可跟随页面，也可固定为浅色或深色；主色可选预设或自定义色值，设置搜索覆盖全部八个分类。

对话正文和输入框宽度也在外观与布局中调整，范围 50%～500%，输入框和加减按钮以 25% 为步进，100% 恢复官方宽度；实际宽度仍受窗口和网页父容器限制。

## Google Drive 备份保存哪些数据？

实验性备份将已保存的书签、高亮、注释及其文件夹存入你自己的 Drive：`AI-MarkDone/Backups/bookmarks`。不包含未保存的临时注释、摘录区、提示词、插件设置或 OAuth 凭据。完整的本地资料库导出包含同一范围；旧书签文件仍可导入，且只影响书签。

备份会校验上传的文件。恢复前可先核对合并预览：保留本地独有条目，跳过重复项，冲突默认保留本地版本。备份需要手动发起，不会自动同步变更。

在数据与备份中可测试连接、管理云端文件。将 Drive 备份移入回收站不会删除本地资料。退出登录会断开 AI-MarkDone 与 Drive 的连接，并清理缓存授权。中断上传可能留下文件；校验失败时会提示是否需要清理。

## 消息导航和目录如何使用？

使用页面右下角的上一条、下一条按钮。启用快捷键后，非输入状态下也可使用左右方向键。

新安装默认开启目录，现有设置保持不变。在设置 → 阅读与消息中可开启或关闭目录，选择紧凑预览或展开列表，并调整摘要、预览长度和右侧距离。滚动加载到的正常消息会逐步补进目录；未加载的历史不一定已包含在内。官网导航显示也在这个分类，导航快捷键在按钮与快捷键中调整，跳转距离在高级设置中调整。

## 字符数如何计算？

这里显示的是加权字符数：常用中日韩字符计为 2，英文字母 A–Z、a–z、数字和下划线计为 1。空格和其他字符不计入；统计会跳过已识别的代码和公式。

字符数下方的时间来自网站消息数据，优先显示更新时间，其次为创建时间；没有真实时间时不显示。
